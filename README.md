# TusneldaX (TSNX)

TusneldaX (TSNX) is a fixed-supply BEP-20 token deployed on BNB Smart Chain.

- Network: BNB Smart Chain (chain ID 56)
- Token standard: BEP-20
- Contract: `0x66a9BaCd6D560383dA967c274999c06550cda07e`
- Decimals: 18
- Maximum and total supply: 100,000,000 TSNX
- Verified source: https://bscscan.com/address/0x66a9BaCd6D560383dA967c274999c06550cda07e#code

## Token allocation

- Liquidity: 10,000,000 TSNX (10%)
- Project reserve: 90,000,000 TSNX (90%)
- Public/private/seed/ICO/IEO/IDO sale: none
- External funding: USD 0; self-funded
- Reserve vesting contract: not currently deployed

## Contract properties

The deployed ABI exposes the standard ERC-20 interface and `MAX_SUPPLY`. It does not expose owner/admin, mint, pause, blacklist, fee, or upgrade functions. The full supply was minted once to the deployer in the constructor.
